## Recent Updates

<Update label="2024-12-15" description="v1.2.0" tags={["feature", "improvement"]}>

## New Features

- Added documentation for new 650-ton press capabilities, enabling larger part production for automotive clients.
- Introduced case studies section with real-world examples from GCC and African markets.

## Improvements

- Enhanced quote request process with faster response times under `<24 hours`.
- Updated industries page to include expanded electronics molding support.

## Bug Fixes

- Fixed display issues on mobile for product galleries.
- Resolved broken links in capabilities overview.

</Update>

<Update label="2024-11-20" description="v1.1.0" tags={["feature", "bugfix"]}>

## New Features

- Launched Arabic language support (`ع`) for full documentation site.
- Added ship-direct QC tracking dashboard for OEM partners.

## Improvements

- Optimized production scheduling UI for `24/7` operations visibility.

## Bug Fixes

- Corrected tool cutting timelines in capabilities docs.
- Patched contact form validation errors.

</Update>

<Update label="2024-10-10" description="v1.0.0" tags={["feature", "breaking"]}>

## New Features

- Initial release of Tawplast documentation hub.
- Core pages for products, industries, markets, and capabilities.

## Breaking Changes

- Restructured navigation from legacy site to new docs format.

## Improvements

- Integrated high-res images for sprayers, blocks, drawers, and cups.

</Update>
